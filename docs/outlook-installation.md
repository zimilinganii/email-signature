# Outlook installation

Follow the [user manual](user-manual.md) for Copy signature, image-free copy, Download HTML and advanced Copy HTML. All routes must end with copying rendered content, not pasting source code.

New Outlook / web: Settings → Accounts → Signatures (or Mail → Compose and reply in some versions), choose account, create a signature, paste, save and choose defaults for new messages/replies.

Classic Outlook for Windows: File → Options → Mail → Signatures → New. Paste, choose account/defaults and confirm. Use HTML message format and keep source formatting if prompted.

Test a new message and received mail. Older Outlook versions may square rounded corners or change spacing. Mobile clients may need separate setup. Outlook automatic installation is not implemented.

[Official Microsoft instructions](https://support.microsoft.com/en-us/outlook/mail/how-to-add-and-change-an-email-signature-in-outlook).
